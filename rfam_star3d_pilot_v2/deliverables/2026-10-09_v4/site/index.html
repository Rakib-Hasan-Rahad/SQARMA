Do Rfam seed alignments match 3D structure correspondences?

Overview Dataset Results 7REX case Validation Downloads Glossary

1. Overview

Research question

When two RNAs of the same family both have experimental 3D structures, does the Rfam standard seed alignment pair up the same nucleotides as a structure-based aligner (original STAR3D)? Where they disagree, which correspondence better preserves the base pairs and stacking seen in the crystal structures (annotated by FR3D)?

Scope

A small pilot: a screened set of Rfam families, a frozen cohort of structure pairs, and STAR3D run in both directions with replicates. Only the standard seed (Rfam.seed.gz, release 15.1) is used as the Rfam reference. The comparison pairs analysed so far are a development set: they were also used to debug the workflow and to design one exploratory adjustment. Pairs are labelled primary (eligible for scientific interpretation) or exploratory (shown for context only).

Headline

Per-pair agreement counts, with denominators, are in Results. The clearest disagreement is in the preQ1-I riboswitch family (RF00522), in the seed row for PDB 7REX, where the 3′ strand of helix P1 appears shifted by one position. This is a candidate for curator review, not a demonstrated error: both supporting comparisons share the same 7REX row, so they are one observation, and in loop L1 the seed's partners fit better than STAR3D's.

Latest validation (v4, 2026-10-09): every reported region has now been reviewed with the same evidence tables; the 7REX P1 candidate survived review and is also consistent with the 7REX authors' own description of P1, while loop L1 favours the seed. Original STAR3D's base-pair selection differs from its paper; re-running with the paper's rule (a separately labelled sensitivity analysis) leaves every preQ1 mapping unchanged but strongly changes the exploratory guanidine-I result. In every Rfam release that ships a structure-curated seed file, its family records are byte-identical to the ordinary seed, so the pilot's baseline for these families is the 3D-curated alignment. A pre-registered attempt to add a family whose seed is not 3D-curated (tRNA) found no primary-eligible pair; one exploratory pair was run and agrees closely with the seed outside a region the bound enzyme refolds.

For each pair, every residue of the source row is placed in exactly one category: the seed and STAR3D give the same partner, a different partner, only the seed gives a partner (rfam only), only STAR3D does (star3d only), or neither. 4. Case study: RF00522 row for 7REX exploratory adjustment

Candidate for curator review, not a demonstrated error. The two supporting comparisons (6VUI→7REX and 3FU2→7REX) are not independent: both comparisons share the 7REX row. The "adjusted row" is an exploratory one-column shift of part of the 7REX row, constructed by the agent to test the hypothesis; it is not an Rfam product.

Supporting evidence

  • The seed's own consensus structure, applied to the 7REX row, implies non-Watson–Crick P1 pairs; the one-column shift makes them Watson–Crick (see validation checks below).
  • The STAR3D register is the one observed in the 7REX crystal structure (FR3D cWW annotations), and it matches the 7REX authors' published description of P1 (a G5–C18 pair in an A28•G5–C18•A29 triple; PMC8752633).
  • The STAR3D mapping of all three preQ1 pairs is unchanged when STAR3D is given only canonical Watson–Crick pairs (sensitivity S1, Method audit below).
  • After superposing on residues where both methods agree, STAR3D partners lie closer than seed partners in the P1 3′ strand (anchor-fit tables below), including when flanking residues are excluded.
  • On the same eligible interaction set, the adjusted row preserves more interactions than the seed row and loses none the seed preserved (table below).

Counterevidence and caveats

  • Loop L1: there the seed is better supported: its partners fit better after superposition, and it maps the 6VUI C7–G11 pair onto 7REX C8–A12, the residues the 7REX authors describe as the pocket-ceiling triple. 7REX binds a second preQ1 that contacts L1 and also residue 16 of the candidate strand.
  • STAR3D builds its alignment from base pairing (including non-canonical pairs in loop scoring), so interaction preservation is supporting, not independent, evidence.
  • Local sequence differs between species in the P1 3′ region; a curator must judge the alignment.
  • Not independent: both comparisons share the 7REX row, so this counts as one observation.

Method audit: how original STAR3D was run and how sensitive it is sensitivity analyses are not the primary method

The STAR3D paper describes stacks built from A–U, C–G and G–U pairs. The released code keeps every cis Watson–Crick-edge pair reported by MC-Annotate (including non-canonical ones), and when one nucleotide has two such partners it silently keeps the last one written. The tables below quantify this and show two separately labelled re-runs: S1 uses only canonical cis Watson–Crick pairs; S2 corrects only the one overwrite found.

Limitations

  • Pilot scale: few families and pairs; families with large models and rRNA were excluded for tractability.
  • Only one structural aligner (STAR3D v1.2, original) and one annotator (FR3D) were used.
  • For the pilot families the ordinary seed is the 3D-curated alignment (identical records), so this is not a sequence-only versus 3D comparison.
  • STAR3D ran under x86-64 emulation on an arm64 Mac; its source pairing rule differs from the paper (see Method audit).
  • Several regions remain "insufficient evidence"; region classifications are an AI agent's review, not a human's.
  • Reruns were performed by the same agent and are not independent validation.
  • Exploratory and engineered-construct pairs are not used for scientific conclusions.

Glossary

Seed alignment
The small, curated multiple sequence alignment that defines an Rfam family. Here: the standard Rfam.seed.gz file, release shown in the footer.
Correspondence
The claim that nucleotide i in one RNA "is the same position" as nucleotide j in another. An alignment column implies correspondences.
STAR3D
A program that aligns two RNA 3D structures and outputs which nucleotides correspond, based on geometry.
FR3D
A program that annotates base pairs and stacking in an RNA 3D structure.
cWW
cis Watson–Crick/Watson–Crick base pair: the standard pairing geometry of helices (includes G–C, A–U and G–U wobble).
Stacking
Bases lying on top of each other, a major stabilising interaction distinct from pairing.
Denominator
The number of items a fraction is taken over. Every fraction here is shown as "x / n" with its unit; when n is zero or missing it is shown as unavailable, not 0.
Eligible
An interaction or residue that can be checked: both ends observed in the structures and not engineered.
Primary / exploratory
Primary pairs passed every predeclared eligibility rule; exploratory pairs are shown for context and are not used for conclusions.
